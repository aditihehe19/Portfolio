# Aditi Kotnala - Cybersecurity & CS Portfolio

A modern, responsive, and SEO-optimized portfolio website for **Aditi Kotnala**, showcasing skills in cybersecurity, cryptography, defensive security engineering, and secure software development.

## ✨ Key Sections

- **Live Activity Tracking**: Real-time GitHub commit heatmap and LeetCode problem-solving tracker
- **Key Projects**: Cryptographic Hash Security Benchmarking Platform, AI Learn (Padhle AI), Structured Knowledge Extraction
- **Interactive Timeline**: Dynamic milestone tracker with the ability to add new events
- **Experience**: Content Writing & Design Lead at Hack Shastra, Content Writer at GDG SRM AP
- **Education**: B.Tech CSE at SRM University AP (CGPA: 8.90/10)
- **Technical Skills**: Cryptography, Python, C++, C, FastAPI, Docker, DBMS, DSA
- **Functional Resume**: Pixel-perfect digital replica of resume with printable styling

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) with Turbopack
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)

## 🔧 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
